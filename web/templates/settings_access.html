Google Calendar

Показывает ожидаемые автомобили из календаря на главной странице. Название события должно содержать номер автомобиля, например ABC123 — замена масла. Поддерживаются также французские, немецкие, греческие и британские номера, а также номера Украины.

Инструкция по подключению
  1. Откройте создание проекта Google Cloud . Примите Terms of Service, если Google попросит, и нажмите Create.
  2. На странице Google Calendar API выберите проект и нажмите Enable.
  3. Откройте мастер доступа Calendar API , выберите Application data и нажмите Next.
  4. Создайте service account с ID mygarage. Роли проекта не назначайте. Откройте вкладку Keys и выберите Add key → Create new key → JSON.
  5. Загрузите JSON-ключ в поле выше, затем откройте настройки Google Calendar .
  6. В разделе «Мои календари» нажмите три точки возле календаря и выберите «Настройки и общий доступ».
  7. Добавьте в общий доступ {{if .CredentialEmail}} {{.CredentialEmail}} {{else}} значение client_email из ключа {{end}} и выберите «Просмотр всех сведений о мероприятиях».
  8. Ниже, в разделе «Интеграция календаря», скопируйте «Идентификатор календаря» в поле Calendar ID. Не используйте адрес service account вместо Calendar ID.

Храните JSON-ключ безопасно. После замены удалите старый ключ в Google Cloud.

Google Drive

Инструкция по подключению
  1. Используйте проект Google Cloud, созданный для календаря, или создайте новый .
  2. На странице Google Drive API выберите проект и нажмите Enable.
  3. Откройте Google Auth Platform и заполните название приложения, например myGarage. Тип аудитории — External.
  4. В разделе Audience нажмите Publish app. В режиме Testing Google отзывает доступ через 7 дней.
  5. В разделе Clients нажмите Create client, выберите тип Desktop app и скачайте JSON.
  6. Загрузите JSON в поле выше и нажмите «Подключить Google Drive».
  7. Войдите в аккаунт Google, на чей диск сохранять копии, и разрешите доступ. Если Google предупредит о непроверенном приложении, выберите Advanced → Go to myGarage.

Токен доступа хранится в папке приложения и не попадает в резервные копии.
